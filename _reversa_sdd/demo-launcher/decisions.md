|---|---------|----------|-----|--------|
| D-1 | Мастер-системы в PoC — заглушки с зафиксированным контрактом; адаптеры работают с ними как с реальными источниками | ADR [0010](../../docs/adr/0010-master-systems-are-stubs.md) | platform/demo-launcher/src/main/java/io/github/unlocker/archrag/demolauncher/DemoLauncher.java:85-106 | 🟢 |
| D-2 | Демо-стенд разворачивается на Docker Compose (CronJob → планировщик в адаптере, NetworkPolicy → раздельные сети, Vault → Docker secrets) | ADR [0021](../../docs/adr/0021-compose-demo-stand.md) | platform/docker/docker-compose.yml:6-36; `platform/docker/entrypoint.sh:1-10` | 🟢 |
| D-3 | Адаптеры и заглушки в репозитории — библиотеки без `main`; один `DemoLauncher` и один образ запускают все роли стенда (адаптер, заглушка, заглушка EAM API) аргументами `command:` | отдельного ADR нет (реализация E5.1; Javadoc пакета) | platform/demo-launcher/src/main/java/io/github/unlocker/archrag/demolauncher/package-info.java:1-6; platform/docker/docker-compose.yml:6-12 | 🟡 (в реестре ADR отсутствует) |
| D-4 | Plain Java без Spring: JDK `HttpServer`, `System.Logger`, конфигурация из env | ADR [0015](../../docs/adr/0015-java21-spring-maven-stack.md) фиксирует стек Java 21/Spring/Maven; отказ от Spring в launcher отдельно не обоснован, решение видно из Javadoc пакета | platform/demo-launcher/src/main/java/io/github/unlocker/archrag/demolauncher/package-info.java:1-6 | 🟡 |
| D-5 | Ровно один экземпляр адаптера на источник (замок snapshot в `Poller` действует только внутри процесса) | кандидат К-7 (`../adrs/candidates.md`), ADR [0006](../../docs/adr/0006-postgres-inbox-event-backbone.md) | platform/demo-launcher/src/main/java/io/github/unlocker/archrag/demolauncher/DemoLauncher.java:44-47; platform/docker/docker-compose.yml:330 | 🟡 |
| D-6 | Миграции журнала накатывает `ingestion-service`, адаптеры стартуют после него | ADR [0006](../../docs/adr/0006-postgres-inbox-event-backbone.md) | platform/demo-launcher/src/main/java/io/github/unlocker/archrag/demolauncher/DemoLauncher.java:44-47; platform/docker/docker-compose.yml:32-36 | 🟢 |
| D-7 | Управляющий вход заглушек (`POST /control/upsert|archive`) — на отдельном порту 8091, не публикуется и не проксируется; нужен сценариям backup/restore, измерений и проверки коммита развёртывания | `docs/03-interfaces.md:560` (сетевая граница), `platform/docker/README.md:51` | platform/demo-launcher/src/main/java/io/github/unlocker/archrag/demolauncher/StubControl.java:16-27; platform/demo-launcher/src/main/java/io/github/unlocker/archrag/demolauncher/EamApiControl.java:15-22 | 🟡 (в docs/03 не описан, Q-12) |
| D-8 | Заглушка шлёт адаптеру подписанный webhook после `control/upsert` (демо-допущение: «внешняя система» — тот же стенд, TLS-proxy не нужен); сбой доставки upsert не откатывает | ADR [0014](../../docs/adr/0014-sla-webhook-to-neo4j.md) (SLA webhook → Neo4j ≤ 30 с); `platform/docker/README.md:221` | platform/demo-launcher/src/main/java/io/github/unlocker/archrag/demolauncher/StubControl.java:23-27, 89-104; platform/docker/docker-compose.yml:385-388 | 🟢 |
| D-9 | `adapter-eam` читает `eam-api-stub` (PLATFORM, SOLUTION, IT_SYSTEM по `id`) и старую `stub-eam` (TEAM, SERVICE_DEPENDENCY): один источник EAM, один snapshot; `ARCHRAG_EAM_MODE=legacy` — откат | `docs/06-eam-integration.md:127-128`; ADR [0030](../../docs/adr/0030-deployment-system-conflict.md) | platform/demo-launcher/src/main/java/io/github/unlocker/archrag/demolauncher/LauncherConfig.java:128-139; platform/demo-launcher/src/main/java/io/github/unlocker/archrag/demolauncher/DemoLauncher.java:137-145; platform/docker/docker-compose.yml:307-329 | 🟡 (отдельного ADR на двухисточниковый режим нет) |
| D-10 | Секреты (пароль PG, ключи S3, секрет webhook, токен EAM API) — Docker secrets, экспортируются `entrypoint.sh`; в записях конфигурации `toString` маскирует значения | ADR [0021](../../docs/adr/0021-compose-demo-stand.md); правило проекта 12 | platform/demo-launcher/src/main/java/io/github/unlocker/archrag/demolauncher/LauncherConfig.java:66-70, 82-84, 91-93; platform/docker/docker-compose.yml:14-26 | 🟢 |
