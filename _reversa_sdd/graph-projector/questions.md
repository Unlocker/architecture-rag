## Сквозные согласования с соседними спецификациями

| Тема соседа | Следствие для проектора | Где в этой спецификации |
|---|---|---|
| `approve` crosswalk не обновляет граф до replay (identity-resolution Q-03) | проектор не имеет операции слияния/перепроекции; `gid` берутся при обработке события | Q-02; [`process-event/design.md`](process-event/design.md) «Получение gid» |
| Tombstone и `Reconciler`: единственный путь удалений; replay пропускает маркер, но воспроизводит строки `reconcile:…` | tombstone-события журнала — источник правды для rebuild; ручной карантин такой строки ломает `finishTombstone` (Q-12) | [`reconcile-missing-set/design.md`](reconcile-missing-set/design.md); Q-12 |
| `SUPERSEDED` недостижим (event-journal R-3, Р-1) | `FINISHED` содержит статус, который проектор никогда не выставляет | Q-01 |
| `CloseAssertion` без производителя (canonical-model Q-3, normalizer Q-03) | ветка проектора мертва для production-потока; замещающую семантику даёт `closeReplacedRelations` | Q-03; [`project-request/design.md`](project-request/design.md) |
| `SyncRun` остаётся `RUNNING` (canonical-model Q-1) | проектор создаёт `SyncRun` только в `RUNNING` | Q-04 |
| Выход из `QUARANTINED` не реализован (event-journal R-2, Р-2) | `quarantine` — практически конечное состояние; практический выход — replay новой строкой `replay:<id>:<eventId>` | [`process-event/design.md`](process-event/design.md) «Обработка ошибок»; Q-12 |
| Нет лимита попыток `RETRYING` (event-journal R-4, П-1) | постоянный `GRAPH_CLIENT_ERROR` и маркер с неполным прогоном повторяются бесконечно | Q-11 |
