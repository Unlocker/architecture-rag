# Spec Impact Matrix

> Architect, этап R.5 (UNLOCKER-270). Отвечает на вопрос «если изменить компонент A, спецификации каких компонентов придётся пересмотреть». Путь `traceability/` — по шаблону skill `reversa-architect`. Метки: 🟢 подтверждено в коде/манифесте · 🟡 выведено · 🔴 связь существует, но компилятором и тестами не защищена.
> Писатель (R.6a) берёт единицы спецификаций из первой колонки §1; связи из §2 нужно отразить в каждой затронутой спецификации явной ссылкой «зависит от…».

## 1. Матрица по зависимостям модулей

Источник — `pom.xml` модулей и граф зависимостей [`../dependencies.md`](../dependencies.md) §3. «Прямо» — зависимость из `pom.xml`; «через данные» — связь только через PostgreSQL, Neo4j, S3 или HTTP, без зависимости в манифесте.

## 3. Сквозные последствия типичных изменений

| Изменение | Какие спецификации затронуты (по §1) | Какие неявные связи (§2) |
|---|---|---|
| Новая метка узла или тип связи | `canonical-model`, `normalizer`, `graph-projector` (`Neo4jSchema`), `graph-query-core` (allowlist'ы), `mcp-server`, `admin-console`, `admin-ui` | № 9, № 4 |
| Новый источник данных | `source-spi`, новый `*-adapter`, `normalizer`, `identity-resolution`, `graph-projector`, `source-stubs`, `docker` | № 2, № 3, № 15, № 16 |
| Новый статус события | `event-schemas`, `event-journal`, `graph-projector`, `ingestion-service`, `admin-console`, `admin-ui` | таблица статусов продублирована в консоли и UI |
| Новый MCP-tool | `graph-query-core` (шаблон), `mcp-server` (tool, `tool-scopes`, аудит), Spring Security | № 8 |
| Смена формата raw payload | `adapter-core`, `ingestion-service`, `graph-projector` (`Reconciler`) | № 1, № 6, № 7 |
| Новая таблица PG | миграция в одном из трёх модулей, консоль (`GRANT` в V6), `ingestion-service` (метрики) | № 5, № 14 |
| Смена схемы Neo4j (свойство, индекс) | `graph-projector`, `graph-query-core`, `admin-console` | № 4 |
| Новый scope или роль | `mcp-server`, `ingestion-service`, `admin-console`, Keycloak realm | [`../permissions.md`](../permissions.md) §2 |

Проверка актуальности: матрица построена по состоянию ветки `epic/UNLOCKER-260` на коммит `ced26f3`; при расхождении с `develop` перепроверьте `grep` по литералам из §2.
