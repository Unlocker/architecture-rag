| D-2 | MCP только читает: отдельный reader-драйвер, `executeRead`, сессия `AccessMode.READ`, проверка `EXPLAIN = READ_ONLY`; запрет записи держит приложение, а не СУБД Community | ADR [0005](../../docs/adr/0005-readonly-mcp-by-application.md), [0001](../../docs/adr/0001-neo4j-derived-read-model.md) | `access/mcp-server/src/main/java/io/github/unlocker/archrag/mcpserver/graph/GraphReaderConfiguration.java:20-39`; `access/graph-query-core/src/main/java/io/github/unlocker/archrag/graphquerycore/GraphQueryExecutor.java:35-36, 78-91, 99-122` | 🟢 (расхождение формулировки — Q-14) |
| D-3 | Агентам доступны предметные tools с параметризованными шаблонами, а не произвольный Cypher; метки и типы связей — из allowlist, обход с верхней границей | ADR [0018](../../docs/adr/0018-domain-tools-not-arbitrary-cypher.md) | `access/mcp-server/src/main/java/io/github/unlocker/archrag/mcpserver/graph/GraphReaderConfiguration.java:51-99`; `access/graph-query-core/src/main/java/io/github/unlocker/archrag/graphquerycore/QueryTemplate.java:125-138` | 🟢 |
| D-4 | Scope на каждый tool, fail-closed: tool без записи в `tool-scopes` отклоняется; проверка идёт на `tools/call` | ADR [0017](../../docs/adr/0017-mcp-streamable-http.md) п. «Ограничения», `../adrs/retroactive-map.md:26` | `access/mcp-server/src/main/java/io/github/unlocker/archrag/mcpserver/security/ToolScopeFilter.java:82-95`; `access/mcp-server/src/main/resources/application.yml:27-34` | 🟢 |
| D-5 | `analyze_impact` реализован как `trace_dependencies(mode=impact)`, а не отдельным tool | ADR [0012](../../docs/adr/0012-trace-dependencies-impact-mode.md) | `access/mcp-server/src/main/java/io/github/unlocker/archrag/mcpserver/tools/TraceDependenciesTool.java:82-158` | 🟢 |
| D-6 | Вне PoC и не реализовано: `compare_environments`, `find_stale_assets`, `search_architecture_context`, `get_sync_status`; есть служебный `ping` | ADR [0022](../../docs/adr/0022-out-of-poc-scope.md), `docs/03-interfaces.md:651` | `access/mcp-server/src/main/java/io/github/unlocker/archrag/mcpserver/tools/PingTool.java:6-22` | 🟢 |
| D-7 | `explain_provenance` не возвращает значения свойств: расхождение показано парой записей (мастер и диссидент) с версией, `fetchedAt`, `contentHash` | ADR [0008](../../docs/adr/0008-authority-matrix-field-level.md) (authority matrix); отдельного ADR на формат нет | `access/mcp-server/src/main/java/io/github/unlocker/archrag/mcpserver/tools/ExplainProvenanceResult.java:5-7` | 🟡 |

| D-9 | Аудит каждого вызова tools в логгер `archrag.audit.mcp` и метрики `archrag.mcp.tool.*` (UNLOCKER-180) | отдельного ADR нет; критерий 9 PoC (p95 по tool) | `access/mcp-server/src/main/java/io/github/unlocker/archrag/mcpserver/audit/ToolCallAuditor.java:18-120` | 🟡 |
