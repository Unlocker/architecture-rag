Кратко

Адаптер источника CMDB (материальные активы: COMPUTE_INSTANCE, виртуальные и физические хосты). Имя модуля asset, код источника cmdb. Модуль не содержит собственной логики: он фиксирует источник SourceSystem.CMDB и собирает типовой SourceAdapter из adapter-core 🟢 (AA/AssetAdapter.java:15-39).

Метки в specs: подтверждено кодом 68, выведено 16, пробелов 15.

  • Маркер модуля AssetAdapterModule (приватный конструктор, нужен «ради непустого JAR») 🟢 (AA/AssetAdapterModule.java:3-7); package-info.java без содержимого 🟢.
границы
  • Нет Neo4j-доступа, нет записи в источник (Javadoc AA/AssetAdapter.java:12-13; AC/SourceAdapter.java:12-16) 🟢.
  • Нет аутентификации к API CMDB: коннектор шлёт только Accept: application/json (AC/HttpSourceConnector.java:81-86) 🟢.
  • Нет разбора полей CMDB: payload объекта идёт в событие как есть, разбирает ingestion/normalizer (CmdbMapper) 🟢.
  • Собственного main() и чтения env нет; запуск - platform/demo-launcher (DemoLauncher.java:142, env ARCHRAG_SOURCE_URL, ARCHRAG_WEBHOOK_SECRET - LauncherConfig.java:24-25) 🟢.
Бизнес-правила
  • source событий этого адаптера - urn:corp:cmdb (EventMapper.sourceUrn, AC/EventMapper.java:47-49; SourceSystem.CMDB("cmdb"), contracts/source-spi/src/main/java/io/github/unlocker/archrag/sourcespi/SourceSystem.java:7) 🟢.
  • create принимает только AdapterConfig с system() == CMDB; иначе IllegalArgumentException("config is for <SYSTEM>, expected CMDB") 🟢 (AA/AssetAdapter.java:34-36).
  • Проверка идёт до создания SourceAdapter, поэтому при чужом config журнал и хранилище не используются (в тесте передаются null) 🟢 (AT/AssetAdapterContractTest.java:49).
  • Пустой или null секрет webhook запрещён (IllegalArgumentException("webhookSecret is required")) - проверка в AdapterConfig, не в модуле 🟢 (AC/AdapterConfig.java:39-41).
  • Значения по умолчанию AdapterConfig.of (наследуются): replayWindow 5 мин, pageSize 100, pollInterval 30 с, reconcileInterval 6 ч, RetryPolicy.defaults() = 5 попыток, 500 мс…30 с 🟢 (AC/AdapterConfig.java:32,57,60-63; AC/RetryPolicy.java:31-33).
  • Имя asset ≠ код cmdb: причина в коде не зафиксирована 🔴 (docs/03-interfaces.md:658).

Основной поток (`create`)
  1. Сравнить config.system() с SYSTEM по ссылке (!=) (AA/AssetAdapter.java:34) 🟢. config == null даст NullPointerException (явной проверки нет) 🟡.
  2. При несовпадении - IllegalArgumentException("config is for " + config.system() + ", expected " + SYSTEM) (:35) 🟢. Сообщение содержит только имена enum, без секретов.
  3. Иначе new SourceAdapter(config, journal, rawStore) (:37) 🟢. Трёхаргументный конструктор сам создаёт new HttpSourceConnector(config.system(), config.sourceBaseUri()) (AC/SourceAdapter.java:29-31) 🟢.
  4. SourceAdapter строит WebhookHandler и Poller (AC/SourceAdapter.java:44-45); запуск (startWebhook, startPolling, startReconciliation) делает вызывающий код 🟢.
Альтернативные потоки
  • Чужой источник → исключение (шаг 2). Тест: AssetAdapterContractTest.adapterIsBoundToItsSource 🟢.
  • Источник с нестандартным API в этом модуле не нужен: используется стандартный HttpSourceConnector; другой коннектор можно передать только прямым вызовом четырёхаргументного конструктора SourceAdapter (AC/SourceAdapter.java:37-41), AssetAdapter такой перегрузки не имеет 🟢.

Состояние

Модуль состояния не хранит (только статические конструкции). Состояние (checkpoint, inbox) - в adapter-core/PostgreSQL 🟢.

Наблюдаемость

Собственного логирования нет. SourceAdapter пишет <code> poll ... / reconcile ... с кодом cmdb и только именем типа исключения (AC/SourceAdapter.java:81-84,106-109) 🟢.

Риски и пробелы
  • 🔴 Реальный API CMDB (аутентификация, пагинация, лимиты) не определён; адаптер работает только с форматом заглушки (docs/05-production-gap-list.md:43; _reversa_sdd/integrations.md:110).
  • 🔴 Причина расхождения имени asset и кода cmdb не записана (docs/03-interfaces.md:658).
  • 🟡 create не проверяет config, journal, rawStore на null; NullPointerException возникнет позже, в adapter-core.
  • 🟡 Тест adapterIsBoundToItsSource выбирает «чужой» источник тернарным выражением (AT/AssetAdapterContractTest.java:44-48); для CMDB оно всегда даёт EAM, и сравнение SYSTEM == EAM избыточно.
