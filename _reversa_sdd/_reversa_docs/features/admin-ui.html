Кратко

SPA админ-консоли (React 18 + TypeScript + Webpack), собирается Maven-модулем через frontend-maven-plugin; hash-роутинг graph/sync, OIDC Authorization Code + PKCE с токеном в памяти, только GET-вызовы /api/**

Метки в specs: подтверждено кодом 323, выведено 93, пробелов 16.

Обзор

admin-ui - одностраничное приложение оператора: два раздела (#/graph «Граф», #/sync «Синхронизация»), все данные берёт из read-only REST access/admin-console (/api/**), логинится в Keycloak публичным клиентом по Authorization Code + PKCE и держит токен только в памяти вкладки 🟢 (access/admin-ui/src/App.tsx:12-49, access/admin-ui/src/auth/authService.ts:39-80, access/admin-ui/src/api/endpoints.ts:47-72). Maven-модуль jar без Java-кода: Webpack-бандл кладётся в target/classes/META-INF/resources, статику отдаёт admin-console 🟢 (access/admin-ui/pom.xml:16, access/admin-ui/webpack.config.js:5-18). Во внешний ingress не публикуется: консоль слушает только 127.0.0.1 (см. ../docker/requirements.md) 🟢.

Ответственности
  • Загрузить публичную конфигурацию OIDC (/console-config.json), завершить вход или уйти на IdP 🟢.
  • Типизированный GET-клиент с Bearer-токеном; реакция на 401 (повторный вход один раз) и 403 (экран «Нет прав») 🟢.
  • Раздел «Граф»: сводка, поиск активов, карточка актива (свойства, жизненный цикл, происхождение), окрестность (Cytoscape) 🟢.
  • Раздел «Синхронизация»: источники-«светофор», журнал событий с карточкой, DLQ, Identity (конфликты и кандидаты), аудит админ-операций 🟢.
  • Показывать данные источников как текст (без HTML) и не раскрывать текст ошибок сервера 🟢.
  • Собираться Maven-ом воспроизводимо (Node/npm закреплены), без runtime-конфигурации в бандле 🟢.
Бизнес-правила
  • Все вызовы API - GET; метод post в клиенте объявлен, но ни одна страница его не вызывает 🟢 (access/admin-ui/src/api/apiClient.ts:35-38, 72-73; access/admin-ui/src/api/endpoints.ts:47-72). Запрет изменяющих операций держит бэкенд: не-GET вне /api/** - denyAll, а контроллеры консоли содержат только @GetMapping 🟢 (access/admin-console/src/main/java/io/github/unlocker/archrag/adminconsole/security/ConsoleSecurityConfiguration.java:48-52; docs/adr/0026-admin-console-readonly-loopback.md:18).
  • Токен и пользователь живут в InMemoryWebStorage; перезагрузка вкладки = новый вход 🟢 (access/admin-ui/src/auth/authService.ts:48).
  • Параллельные 401 запускают вход один раз; провал входа показывает «Не удалось выполнить вход. Обновите страницу.» 🟢 (access/admin-ui/src/api/ApiContext.tsx:20-28, 33-35).
  • 403 в одном разделе показывает экран «Нет прав» только в этом разделе; смена раздела (key={route}) сбрасывает его 🟢 (access/admin-ui/src/App.tsx:43-45; access/admin-ui/src/api/ApiContext.tsx:29, 36).
  • Неизвестный hash ведёт в «Граф» 🟢 (access/admin-ui/src/useHashRoute.ts:11-14).
  • Пустой поисковый запрос не отправляется; запрос ограничен 200 символами в поле ввода 🟢 (access/admin-ui/src/pages/graph/AssetSearch.tsx:19, 41).
  • Ответ устаревшего поискового запроса не затирает ответ более нового 🟢 (access/admin-ui/src/pages/graph/AssetSearch.tsx:14, 21-26).
  • Размер страницы всех таблиц - 50 (сервер допускает 1..200) 🟢 (access/admin-ui/src/pages/sync/EventsTab.tsx:8; access/admin-console/src/main/java/io/github/unlocker/archrag/adminconsole/pg/PageRequest.java:10-11, 20-22).
  • Окрестность: глубина только 1 или 2 (сервер: 1..2); при truncated показывается баннер 🟢 (access/admin-ui/src/pages/graph/NeighborhoodView.tsx:23-29, 41-45; access/admin-console/src/main/java/io/github/unlocker/archrag/adminconsole/api/GraphController.java:44).
  • Фильтры списков (источник, статус, период, DLQ) сбрасывают страницу на первую 🟢 (access/admin-ui/src/pages/sync/EventsTab.tsx:64-69; access/admin-ui/src/pages/sync/DlqTab.tsx:27-38).
  • Значения свойств, причин и значений конфликтов выводятся как текст React; URL репозитория - текстом, не ссылкой; подписи узлов графа рисуются на canvas 🟢 (access/admin-ui/src/components/common.tsx:65-69; access/admin-ui/src/pages/graph/AssetCard.tsx:15, 25; access/admin-ui/src/components/GraphCanvas.tsx:6-9).
  • Сообщение об ошибке - только «Ошибка запроса (HTTP N)» или общее; тело ответа сервера не показывается 🟢 (access/admin-ui/src/hooks/useAsync.ts:9-13).
  • 🟡 Порог «устарел» (7 суток), пороги lag светофора (15 мин, 60 мин), allowlist'ы типов, источников и статусов - константы UI, продублированные с бэкендом и не связанные с ним кодом (access/admin-ui/src/api/constants.ts:1-63) - Q-04, Q-05.

Старт приложения
  1. index.tsx: loadConsoleConfig() → root.render(<App auth={createOidcAuthService(config)} />); при отказе - <p role="alert">Не удалось загрузить конфигурацию консоли.</p> (access/admin-ui/src/index.tsx:6-10) 🟢.
  2. App (useEffect по auth): auth.init(); true → ready; false → auth.login() (редирект на IdP); исключение → failed (access/admin-ui/src/App.tsx:16-33) 🟢. Флаг cancelled защищает от обновления размонтированного компонента (access/admin-ui/src/App.tsx:17-32) 🟢.
  3. pending → <p>Вход…</p>; failed → <p role="alert">Не удалось выполнить вход. Обновите страницу.</p> (access/admin-ui/src/App.tsx:35-40) 🟢.
  4. ready → Layout с ApiProvider key={route} и страницей по route (access/admin-ui/src/App.tsx:41-48) 🟢.

Детали входа и обработки 401/403 - oidc-login/design.md.

Состояние и загрузка данных
  • Глобального стора нет. Серверные данные - useAsync; локальные фильтры, страницы и выбранный актив - useState страницы (access/admin-ui/src/pages/GraphPage.tsx:9, access/admin-ui/src/pages/sync/EventsTab.tsx:50-55) 🟢.
  • useAsync: эффект зависит от [...deps, tick]; при смене deps показывает «Загрузка…» (silent=false), по таймеру (refreshMs) - тихое обновление без сброса (silent=true); reload() увеличивает tick (access/admin-ui/src/hooks/useAsync.ts:24-55) 🟢.
  • 🟡 NeighborhoodView передаёт массив relTypes в зависимости useAsync; новый массив создаётся при каждом переключении чекбокса, поэтому эффект срабатывает ровно на изменение выбора (access/admin-ui/src/pages/graph/NeighborhoodView.tsx:13-18).

Безопасность клиента
  • Аутентификация: Bearer из памяти; Authorization не отправляется, если токена нет или он просрочен (getAccessToken() → null), и сервер отвечает 401 (access/admin-ui/src/api/apiClient.ts:45-48, access/admin-ui/src/auth/authService.ts:76) 🟢.
  • Вывод данных: React экранирует текст; dangerouslySetInnerHTML в коде нет (проверено поиском по access/admin-ui/src) 🟢.
  • CSP: бандл без inline; сервер ставит default-src 'self'; connect-src 'self' <origin issuer>; frame-ancestors 'none'; base-uri 'self'; object-src 'none' (access/admin-console/src/main/java/io/github/unlocker/archrag/adminconsole/security/ConsoleSecurityConfiguration.java:61-66) 🟢. Запросы UI идут на свой origin (API) и на origin issuer (token endpoint oidc-client-ts) 🟡 (адреса token endpoint определяет библиотека по discovery).
  • Секретов в бандле нет: issuer, clientId, scope приходят с сервера (access/admin-ui/src/auth/authService.ts:3-8, 22-32) 🟢.
