# platform/integration-tests: внешние контракты

> Что модуль требует от окружения и что подаёт на вход тестируемым приложениям: команды запуска, образы, свойства, JWT, фикстуры, бюджеты времени. Секреты не приводятся: только имена констант. Открытые вопросы — [`questions.md`](questions.md). Поведение — [`requirements.md`](requirements.md), [`design.md`](design.md).

## 1. Запуск и CI

| Команда | Эффект | Трассировка |

README требует запущенный Docker (`README.md:44`) 🟡.

Claims `McpTestJwt` 🟢 (`platform/integration-tests/src/test/java/io/github/unlocker/archrag/integrationtests/McpTestJwt.java:64-86`): `iss = RESOURCE` (`https://mcp.test/mcp`), `sub` (по умолчанию `test-user`), `aud = RESOURCE` либо параметр, `azp = archrag-demo` либо параметр, `iat = now − 60 с`, `exp = now + 5 мин` (не настраивается), `scope` — через пробел (может быть пустым).
