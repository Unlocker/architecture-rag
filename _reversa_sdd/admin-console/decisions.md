# access/admin-console: решения

| № | Решение | Источник | Код | Статус |
|---|---------|----------|-----|--------|
| D-1 | Консоль — отдельный read-only сервис: граф под reader-учёткой Neo4j (`executeRead`), журнал под ролью PostgreSQL `archrag_console_ro` (только `SELECT`, миграция V6); writer-секретов нет | ADR [0026](../../docs/adr/0026-admin-console-readonly-loopback.md), [0005](../../docs/adr/0005-readonly-mcp-by-application.md) | `access/admin-console/src/main/java/io/github/unlocker/archrag/adminconsole/graph/GraphReaderConfiguration.java:18-32`; `access/admin-console/src/main/java/io/github/unlocker/archrag/adminconsole/pg/ConsolePgConfiguration.java:12-30`; `ingestion/ingestion-service/src/main/resources/db/migration/V6__console_readonly_role.sql:14-16` | 🟢 |
| D-2 | Доступ к API — OIDC resource server: scope `architecture.admin`, собственный audience (`urn:archrag:console`), публичный клиент `archrag-admin-console` (Authorization Code + PKCE S256) | ADR 0026 | `access/admin-console/src/main/java/io/github/unlocker/archrag/adminconsole/security/ConsoleSecurityConfiguration.java:44-45`; `access/admin-console/src/main/java/io/github/unlocker/archrag/adminconsole/config/ConsoleProperties.java:22-27`; `platform/docker/keycloak/archrag-realm.json:77-90` | 🟢 |
| D-3 | На стенде консоль и Keycloak публикуются только на `127.0.0.1`; через reverse proxy консоль не публикуется, в сети `edge` её нет | ADR 0026 | `platform/docker/docker-compose.yml:290-293, 543` | 🟢 (в приложении привязки нет, Q-01) |
| D-4 | Токен консоли не проходит в admin REST ingestion: тот проверяет `azp` по allow-list (сторона ingestion) | ADR 0026 | `ingestion/ingestion-service/src/main/java/io/github/unlocker/archrag/ingestionservice/AuthorizedPartyValidator.java:26-31` (вне модуля) | 🟢 (в консоли проверки `azp` нет, Q-02) |
| D-5 | Изменяющих операций в UI нет; reconcile, replay, rebuild, crosswalk остаются в admin REST ingestion | ADR [0013](../../docs/adr/0013-operator-ops-via-admin-endpoint.md), 0026 | контроллеры содержат только `@GetMapping`: `access/admin-console/src/main/java/io/github/unlocker/archrag/adminconsole/api/GraphController.java:56-127` | 🟢 |
| D-6 | Граф читается только именованными шаблонами `graph-query-core` через `GraphReads`; окрестность — глубина ≤ 2, типы связей из allowlist, бюджет узлов, `truncated` | ADR [0018](../../docs/adr/0018-domain-tools-not-arbitrary-cypher.md), 0026 | `access/admin-console/src/main/java/io/github/unlocker/archrag/adminconsole/graph/GraphReads.java:13-45`; `access/admin-console/src/main/java/io/github/unlocker/archrag/adminconsole/api/GraphController.java:43-44, 127-167` | 🟢 |
| D-7 | Raw payload не отдаётся: только `payloadRef` и `contentHash` | ADR 0026 | `access/admin-console/src/main/java/io/github/unlocker/archrag/adminconsole/pg/Rows.java:6-9, 14-32` | 🟢 |
| D-8 | Токен в браузере хранится только в памяти; CSP `default-src 'self'`, `connect-src` = origin issuer | ADR 0026 | `access/admin-console/src/main/java/io/github/unlocker/archrag/adminconsole/security/ConsoleSecurityConfiguration.java:57-66` (CSP); хранение токена — код `admin-ui` | 🟢/🟡 |
| D-9 | Чтения консоли аудируются логом `archrag.audit.console` (`sub`, шаблон маршрута, ID шаблонов, строки, `truncated`, статус, длительность) | ADR 0026; кандидат К-8 `../adrs/candidates.md:92` | `access/admin-console/src/main/java/io/github/unlocker/archrag/adminconsole/audit/ReadAuditInterceptor.java:15-58` | 🟡 (аудит-лог не таблица, retention не определён) |
| D-10 | Ролевого ограничения внутри `architecture.admin` нет: любой пользователь realm получает токен консоли; принято владельцем 2026-10-08 как ограничение PoC | ADR 0026; gap list п. 2.7 (`docs/05-production-gap-list.md`) | `access/admin-console/src/main/java/io/github/unlocker/archrag/adminconsole/security/ConsoleSecurityConfiguration.java:44-45` | 🟡 |
| D-11 | Коды источников и статусы событий продублированы в `SyncSources`, чтобы консоль не зависела от `ingestion/*` | схема модулей `CLAUDE.md` | `access/admin-console/src/main/java/io/github/unlocker/archrag/adminconsole/pg/SyncSources.java:6-33` | 🟡 (ADR нет; дубль, Q-08) |
| D-12 | Пул PostgreSQL ленивый, health-проба БД отключена: консоль жива без PostgreSQL (граф и статика работают) | комментарий конфигурации | `access/admin-console/src/main/java/io/github/unlocker/archrag/adminconsole/pg/ConsolePgConfiguration.java:33-34`; `access/admin-console/src/main/resources/application.yml:46-50` | 🟡 |

Расхождения кода с ADR: не найдены. Расхождения с `docs/03-interfaces.md`: не найдены в части перечня маршрутов (`docs/03-interfaces.md:410-415`). Пробелы — в [`questions.md`](questions.md).
