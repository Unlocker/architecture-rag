# 0024. Формат `sourceId`: `'1042'` или `'EAM-1042'`

- **Статус:** Предложено
- **Дата:** —
- **Источник:** [`00-vision.md`, «Идентичность узлов»](../00-vision.md#идентичность-узлов)
- **Кто принял:** владелец (решение не принято)

## Контекст

В примере `SourceRecord` в видении `sourceId` равен `'1042'`, а в каноническом событии — `'EAM-1042'`. `source` уже хранится отдельным полем.

## Решение

**Ждёт решения владельца.** Решение не принято. До него оба примера остаются в видении как есть.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| `'1042'` — идентификатор источника как есть | Совпадает с `source`-полем, нет дублирования | Нужен `source` для однозначности | Не выбран |
| `'EAM-1042'` — с префиксом источника | Читается без контекста | Дублирует `source` | Не выбран |

## Последствия

- **Положительные:** —
- **Отрицательные / ограничения:** Пока формат не выбран, адаптеры и тесты не должны полагаться на префикс.
- **Затронутый код:** `contracts/canonical-model/...`, адаптеры
