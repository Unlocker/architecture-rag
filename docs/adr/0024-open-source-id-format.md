# 0024. Формат `sourceId` — ключ источника без префикса системы

- **Статус:** Принято
- **Дата:** 2026-10-10
- **Источник:** UNLOCKER-247; [`00-vision.md`, «Идентичность узлов»](../00-vision.md#идентичность-узлов)
- **Кто принял:** владелец

## Контекст

В примере `SourceRecord` в видении `sourceId` равен `'1042'`, а в каноническом событии — `'EAM-1042'`. `source` уже хранится отдельным полем.

## Решение

`sourceId` — собственный ключ записи в источнике **без префикса системы**: `'1042'`, а не `'EAM-1042'`. Система источника хранится в отдельном поле `source` ([ADR 0003](0003-gid-and-source-record-identity.md)). Для реального EAM это целочисленный `id` объекта ([`06-eam-integration.md`, «Сопоставление ключей»](../06-eam-integration.md#сопоставление-ключей)). Строковые `EAM-…` — значение системного поля `eam_id`, а не ключ источника.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| `'1042'` — идентификатор источника как есть | Совпадает с `source`-полем, нет дублирования | Нужен `source` для однозначности | Выбран |
| `'EAM-1042'` — с префиксом источника | Читается без контекста | Дублирует `source` | Отклонён |

## Последствия

- **Положительные:** ключ `(source, sourceType, sourceId)` не дублирует систему в `sourceId`; формат совпадает с реальным EAM.
- **Отрицательные / ограничения:** старая заглушка `StubSources.eam` использует строковые id `EAM-…` как legacy-демо, это записано в [`06-eam-integration.md`](../06-eam-integration.md#заглушки-и-fixtures). Пример CloudEvent в [`00-vision.md`](../00-vision.md#каноническое-событие) с `sourceId: 'EAM-1042'` устарел (приведён к решению 2026-10-10).
- **Затронутый код:** код уже соответствует решению; правится только документация.
