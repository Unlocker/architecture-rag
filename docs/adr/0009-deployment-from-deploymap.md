# 0009. `Deployment` берётся из deploy map и Helm charts отдельным адаптером `deploymap-adapter`

- **Статус:** Принято
- **Дата:** 2026-10-03
- **Источник:** владелец 2026-10-03 (решение 2); UNLOCKER-165; [`00-vision.md`, «Provenance и авторитетность»](../00-vision.md#provenance-и-авторитетность)
- **Кто принял:** владелец

## Контекст

Ранее мастером `Deployment` называли «CD/Kubernetes или CMDB». Фактически состав развёртываний на стенде описан в deploy map и Helm charts.

## Решение

Мастер `Deployment` на стенде — deploy map и Helm charts. Они читаются отдельным адаптером `deploymap-adapter`; SCM даёт дополнительные метаданные.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| Отдельный `deploymap-adapter` | Мастер совпадает с реальным источником | Ещё один адаптер | Выбран |
| CD/Kubernetes или CMDB (прежний вариант) | — | Не отражает источник на стенде | Заменён |
| Брать из SCM | Меньше адаптеров | SCM не владеет развёртыванием | Отклонён |

## Последствия

- **Положительные:** Четыре адаптера: eam, scm, asset, deploymap.
- **Отрицательные / ограничения:** Контракт deploy map нужно зафиксировать заглушкой.
- **Затронутый код:** `adapters/deploymap-adapter`
