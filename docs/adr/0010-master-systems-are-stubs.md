# 0010. Мастер-системы в PoC — заглушки

- **Статус:** Принято
- **Дата:** 2026-10-03
- **Источник:** владелец 2026-10-03 (решение 3); [`00-vision.md`, «Provenance и авторитетность»](../00-vision.md#provenance-и-авторитетность)
- **Кто принял:** владелец

## Контекст

Реальных API мастер-систем для PoC нет или доступ не согласован.

## Решение

Адаптеры работают с заглушками, повторяющими зафиксированные контракты. Реальные интеграции подключаются после PoC. SLA и замеры (ADR 0014) относятся к заглушкам.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| Заглушки с зафиксированным контрактом | PoC не зависит от внешних систем | Реальные особенности API не проверены | Выбран |
| Реальные API сразу | Реалистичные данные | Доступ, сроки, нестабильность | Отклонён для PoC |

## Последствия

- **Положительные:** Стенд воспроизводим. SPI `source-spi` держит границу.
- **Отрицательные / ограничения:** Контракты нужно будет сверять с реальными API: пункт production gap list.
- **Затронутый код:** `contracts/source-spi`, `adapters/*`
