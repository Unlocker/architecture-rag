# 0018. Агентам — предметные tools с параметризованными шаблонами, не произвольный Cypher

- **Статус:** Принято
- **Дата:** 2026-10-03
- **Источник:** [`00-vision.md`, «Почему не arbitrary Cypher»](../00-vision.md#почему-не-arbitrary-cypher)
- **Кто принял:** архитектор, принято владельцем

## Контекст

Официальный Neo4j MCP умеет `read-cypher`, но проверка read-only обходится кастомными процедурами. Агентам нужны предсказуемая стоимость и фильтрация по домену.

## Решение

Агентам доступны предметные tools с параметризованными Cypher-шаблонами. Метки и типы связей берутся из allowlist. Обход всегда с верхней границей глубины. `read_cypher` в PoC не включается.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| Предметные tools + шаблоны | Предсказуемая цена, фильтрация, устойчивость к prompt injection | Каждый сценарий — отдельный шаблон | Выбран |
| Arbitrary Cypher (`read-cypher`) | Гибкость | Непредсказуемая цена, обход read-only | Отклонён для агентов |

## Последствия

- **Положительные:** Стабильная телеметрия по use case.
- **Отрицательные / ограничения:** Новый сценарий требует кода.
- **Затронутый код:** `access/graph-query-core`
