# 0013. Операции оператора идут через админский эндпоинт ingestion-сервиса

- **Статус:** Принято
- **Дата:** 2026-10-03
- **Источник:** владелец 2026-10-03 (решение 8); UNLOCKER-170; [`00-vision.md`, «Сценарии адаптеров»](../00-vision.md#сценарии-адаптеров)
- **Кто принял:** владелец

## Контекст

Replay, rebuild, reconcile и загрузка crosswalk меняют витрину. Их нельзя отдавать агентам через MCP.

## Решение

Операции выполняются через админский эндпоинт ingestion-сервиса: он не входит в MCP, доступен только во внутренней сети и защищён отдельным OIDC scope. Оформление как Kubernetes `Job` — позже, после PoC.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| Админский эндпоинт ingestion-сервиса | Отдельная граница доступа, не в MCP | Ещё одна поверхность | Выбран |
| Операции как MCP tools | Единая точка | Агенты получают write-путь | Отклонён |
| Kubernetes Job | Стандартный запуск | Стенд на Compose, объём работ | Отложен |

## Последствия

- **Положительные:** MCP остаётся read-only.
- **Отрицательные / ограничения:** Нужна защита эндпоинта: scope и сеть.
- **Затронутый код:** `ingestion/*`
