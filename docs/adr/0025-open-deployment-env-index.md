# 0025. Индекс `deployment_env` по несуществующему `environmentKey`

- **Статус:** Предложено
- **Дата:** —
- **Источник:** UNLOCKER-162; [`00-vision.md`, «Constraints и indexes»](../00-vision.md#constraints-и-indexes)
- **Кто принял:** владелец (решение не принято)

## Контекст

Индекс `deployment_env` построен по `Deployment.environmentKey`, а в модели окружение задаётся связью `IN_ENVIRONMENT`.

## Решение

**Ждёт решения владельца.** Варианты: добавить свойство `environmentKey` в модель `Deployment` либо перестроить индекс. Решение не принято.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| Добавить `environmentKey` в `Deployment` | Быстрый фильтр по окружению | Денормализация, риск расхождения со связью | Не выбран |
| Перестроить индекс | Модель не меняется | Фильтр идёт через связь | Не выбран |

## Последствия

- **Положительные:** —
- **Отрицательные / ограничения:** До решения индекс не должен считаться рабочим.
- **Затронутый код:** `ingestion/graph-projector/.../schema/Neo4jSchema.java`
