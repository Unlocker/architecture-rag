# 0008. Authority matrix на уровне полей и связей; мастер `DEPENDS_ON` — EAM

- **Статус:** Принято
- **Дата:** 2026-10-03
- **Источник:** владелец 2026-10-03 (решение 1); UNLOCKER-161; [`00-vision.md`, «Provenance и авторитетность»](../00-vision.md#provenance-и-авторитетность)
- **Кто принял:** владелец

## Контекст

Разные системы подтверждают разные атрибуты одного актива. Без правил старшинства неясно, чья версия значения побеждает и кто владеет связью `DEPENDS_ON`.

## Решение

Для каждого типа атрибута и связи фиксируется мастер и допустимые дополнения. Мастер `DEPENDS_ON` между сервисами — EAM, SCM даёт метаданные. Матрица живёт в коде и применяется при проекции.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| Матрица на уровне полей и связей | Точное старшинство, объяснимый provenance | Матрицу нужно сопровождать | Выбран |
| Мастер на уровне типа узла | Проще | Теряет случаи, где поля одного узла разных мастеров | Отклонён |
| Last-write-wins | Без матрицы | Нестабильный результат, ложные связи | Отклонён |

## Последствия

- **Положительные:** Конфликты источников разбираются по явным правилам.
- **Отрицательные / ограничения:** Изменение мастера — изменение кода и ADR.
- **Затронутый код:** `contracts/canonical-model/...` (authority matrix)

## Уточнение 2026-10-14

Решение владельца (UNLOCKER-276, вопрос 7). Исходный текст выше не меняется. Истина — код (`AuthorityMatrix.defaults()`).

- Мастер `DECOMPOSED_INTO` (ITSystem → Service) и `IMPLEMENTED_IN` — SCM; EAM остаётся мастером `DEPENDS_ON`, `OWNED_BY`, `USES_SOLUTION`, `USES_PLATFORM`. Свойства узлов, закреплённые за EAM явно: `ITSystem.criticality`, `eamCode`, `platformId`, `Solution.platformId` ([0031](0031-it-system-platform-invariant.md)).
- `PART_OF` и `HOSTED_ON` нетемпоральны намеренно (`RelationType`, `temporal=false`): `PART_OF` в PoC не наполняется ([0011](0011-namespace-cluster-modeled-not-populated.md)), `HOSTED_ON` нормализатор не строит. Остальные бизнес-связи темпоральны ([0028](0028-structural-relations-temporal.md)).
